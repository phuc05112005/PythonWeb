HUONG DAN CHAY DU AN TREN MAY MOI (WINDOWS)

Dieu kien ban dau:
1. Da cai Python (khuyen nghi 3.13) va da add vao PATH.
2. Da cai PostgreSQL + pgAdmin.
3. Da cai VS Code.
4. Da co source code du an (clone/paste thu muc PythonWeb).

==================================================
A. MO DU AN TREN MAY MOI
==================================================
1. Mo VS Code -> Open Folder -> chon thu muc PythonWeb.
2. Mo Terminal trong VS Code (Terminal > New Terminal).
3. Di chuyen vao thu muc goc du an (neu chua dung cho):
   cd d:\Class\GIS_Progamming\gisweb\PythonWeb

==================================================
CAI THU VIEN TU requirements.txt
==================================================
1. Nang cap pip:
   python -m pip install --upgrade pip

2. Cai tat ca thu vien cua du an:
   pip install -r requirements.txt

==================================================
C. TAO DATABASE POSTGRESQL
==================================================
Du an dang dung thong so DB nhu sau (trong clothing_store/settings.py):
- DB NAME: shopthoitrang
- USER: postgres
- PASSWORD: 123
- HOST: 127.0.0.1
- PORT: 5432


Cach tao va dong bo co so du lieu trong pgAdmin:
1. Dang nhap server PostgreSQL.
2. Right click Databases -> Create -> Database...
3. Dat ten: shopthoitrang
4. restore file shopthoitrang.backup vao Database trong PgAdmin

==================================================
D. CHAY MIGRATION
==================================================
Chay migration:
   python manage.py migrate

==================================================
E. CHAY DU AN
==================================================
1. Bat server:
   python manage.py runserver

2. Mo trinh duyet: http://127.0.0.1:8000/

==================================================
THAM KHAO TAI LIEU/FILE BO SUNG
==================================================
Backup DB:
Document\shopthoitrang.backup
